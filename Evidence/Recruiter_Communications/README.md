# Recruiter Communications

This directory contains the recruiter communications collected during the investigation into a suspected multi-domain recruitment campaign.

The conversations represent the primary behavioral evidence used throughout the investigation and provide first-hand documentation of the campaign's progression from initial recruiter contact through onboarding, infrastructure migration, operational tasking, financial escalation, and campaign closure.

All communications were collected through voluntary interaction during a real-world recruitment process and have been preserved as evidence to support Cyber Threat Intelligence (CTI) analysis.

---

# Purpose

The recruiter communications support multiple aspects of the investigation, including:

- Campaign timeline reconstruction
- Social engineering analysis
- Behavioral analysis
- Infrastructure correlation
- Threat intelligence reporting
- Indicator development
- Detection engineering
- Confidence assessment

These communications form the foundation for many of the analytical conclusions documented elsewhere in this repository.

# Evidence Integrity

The original recruiter communications have been preserved in their entirety.

Only formatting changes have been made to convert the conversations into Markdown documents suitable for documentation and repository organization.

No conversational content has been modified, removed, or reordered.

Each communication is treated as an individual evidence artifact and assigned a unique evidence identifier (`COMM-001` through `COMM-006`) to facilitate traceability throughout the investigation.
