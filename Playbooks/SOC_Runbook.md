# SOC Runbook

## Tier 1

- Validate alert.
- Check domain against IOC list.
- Review user activity.
- Escalate if confirmed.

---

## Tier 2

- Perform endpoint analysis.
- Review network telemetry.
- Correlate with campaign indicators.
- Determine scope.

---

## Tier 3

- Conduct deep forensic analysis.
- Update detection content.
- Produce intelligence report.
- Coordinate long-term mitigations.
