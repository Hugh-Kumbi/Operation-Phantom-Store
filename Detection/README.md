# Detection Engineering

## Overview

This directory contains detection content developed from the Operation Phantom Store investigation.

Unlike the intelligence reports contained elsewhere in this repository, these artefacts are intended to be deployed by defenders to detect campaign activity within enterprise environments.

The rules were derived from observed infrastructure, backend communications, application behaviour, and network indicators documented during the investigation.
